# 自带 API Key：配置、推荐与排错

适用于 DayMate 0.8.0。DayMate 不出售模型额度，也不要求注册 DayMate 账号。基础任务、统计、每日内容、渐变背景、心情排序和离线音乐不需要密钥。

## 最快上手

1. 在服务商官网创建自己的 API Key，确认有余额或可用额度及模型权限。
2. 打开“设置 → AI 服务”，选择创建密钥的服务商，核对接收地址。
3. 粘贴到密码框，点击“保存密钥”。密钥只进入 Windows 凭据管理器。
4. 点击“获取可用模型”，筛选并选择一个文本对话模型；不支持模型目录的服务仍可手动填写。
5. 点击“测试连接”。只有收到有效正文才算成功，不以 HTTP 200 或存在模型名称代替验证。
6. 开启 AI 增强，到“每日内容”选择场景、心情，再使用音乐推荐或独立鼓励入口。发送前会展示字段和接收地址，确认后才请求。

切换服务商后，各自的地址和模型会保留；只保存这些普通配置，不把密钥放入偏好。修改接收地址后必须重新确认并保存密钥，不能把同一个 Key 自动转发给另一个平台。

“获取模型”只获取目录，不发送聊天消息，但会计入本机每日请求数。目录可见不代表免费、不代表当前账号已经获得全部模型权限。测试和生成可能按服务商定价收费；本机每日次数限制不是余额或金额限制。

## 硅基流动、千问与 GLM 的区别

| 项目                 | 在 DayMate 中怎么选                                                      |
| -------------------- | ------------------------------------------------------------------------ |
| 硅基流动创建的 Key   | 服务商选“硅基流动”，地址 `https://api.siliconflow.cn/v1`                 |
| 在硅基流动用千问     | 在该平台的模型列表筛选 `Qwen/`，例如 `Qwen/Qwen3-8B`；最终以账号实测为准 |
| 在硅基流动用 GLM     | 仍选“硅基流动”，选择目录里的 GLM 模型，不换成智谱官方地址                |
| 智谱官网创建的 Key   | 服务商选“智谱 GLM”，使用其官方地址与模型权限                             |
| 阿里云百炼创建的 Key | 服务商选“阿里云百炼 / 通义千问”，不能沿用硅基流动密钥                    |

模型名称不等于服务商名称。不同平台托管同一家模型，密钥、费用和权限仍由接入的平台管理。

硅基流动的目录接口是 `GET /v1/models?sub_type=chat`，不是 `type=chat`。对话为 `POST /v1/chat/completions`。DayMate 不强制升级已保存模型，也不自动选择列表中更贵的型号。[官方模型接口](https://docs.siliconflow.cn/docs/api/models-get)、[官方对话接口](https://docs.siliconflow.cn/docs/api/chat-completions-post)

对硅基流动官方接口中已确认支持切换思考模式的 Qwen3 型号，DayMate 使用非思考模式完成短推荐；不会向所有服务商或自定义网关套用专有参数。模型退役、实名认证和额度政策会变化，遇到问题先重新获取模型并测试。[官方更新说明](https://docs.siliconflow.cn/docs/release-notes/overview)

## 商汤日日新

文本接口根地址为 `https://token.sensenova.cn/v1`，新配置默认使用 `sensenova-6.8-flash-lite`；已有用户配置不会被悄悄替换。模型目录包括不同能力，选择对话时应选输出文本的模型，不能把图片模型填到聊天栏。[商汤模型目录](https://platform.sensenova.cn/docs#list-models)

SenseNova 6.8 的输出预算包含推理内容。旧版极短预算可能只产生推理而没有正文。DayMate 对该官方接口和型号单独使用最多 2000 输出 Token、60 秒超时；不显示或保存模型推理内容，截断或无正文仍作为失败，不盲目重试。[商汤官方 API 指南](https://github.com/OpenSenseNova/SenseNova6.8/blob/main/API.md)

### 图片能力与本轮边界

官方新网关已提供 `POST /v1/images/generations`，使用 Bearer Key；当前文档列出 `sensenova-u1.5-lite`。它支持 `response_format: "b64_json"`、`n: 1`，还需指定提示词、尺寸等图片参数。它与文本对话不是同一个请求格式；旧 AK/SK/JWT 文档也不能与新网关混接。[商汤图片接口](https://platform.sensenova.cn/docs#image-generations)

0.7.0 已核对图片接入方式，0.8.0 仍没有上线图片生成或后台每日收费生图。应用背景仍是本地渐变，不会因为保存文字模型 Key 就自动调用图片接口。图片权限、费用、结果校验和保存需要单独验收；不能把文本连接成功当作生图已经验证。本轮没有发起图片生成请求。

## 音乐与鼓励会发送什么

| 操作     | 发给 AI 的内容                                                                               | 不会发送                                         |
| -------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 测试连接 | 固定测试短句                                                                                 | 任务、活动、搜索记录                             |
| 获取模型 | 无聊天消息，仅鉴权获取目录                                                                   | 心情、任务、活动                                 |
| 音乐推荐 | 音乐偏好、自选场景、自选心情、音乐意图、当前小时；主动开启分享时追加活跃分钟和未完成任务数量 | 应用名称、窗口标题、任务全文、播放历史、音乐反馈 |
| 独立鼓励 | 自选场景、心情、当前小时、陪伴语气                                                           | 活动摘要、任务和音乐搜索词                       |

心情由自己选择，DayMate 不根据鼠标、按键或应用使用记录诊断情绪。AI 只挑选受限音乐类别和普通文字，不控制程序、不生成播放地址、不绕过音乐版权权限。

音乐推荐只影响本次推荐，不改写长期音乐偏好；切换音乐、生成鼓励不会改动每日好句。所有按钮均有独立状态。结果会注明 AI、缓存或本地来源，失败时仍能继续使用本地内容。

“按心情推荐”使用本地检索计划与排序，不需要 Key；“AI 推荐”先取得受控类别建议，再走同一真实曲目候选链路。`match` 表示陪伴此刻，`lift` 表示提一点精神；休息/睡眠场景仍优先安静。喜欢/不喜欢只参与本地排序，AI 不会看到这些记录。检索、排序权重和证据边界见[工程手册](engineering-handbook.md)，本版实测见[验证记录](verification-v0.8.0.md)。

音乐播放来自 Audius 允许公开流播的曲目，离线兜底为随包 CC0 曲目。AI Key 不是音乐平台会员，也不会使《天下》等所有商业歌曲自动可播。搜索词会发给 Audius，用户合法拥有的音频可本地导入。

## 错误怎么处理

| 提示或状态                 | 建议                                                                  |
| -------------------------- | --------------------------------------------------------------------- |
| 密钥与当前接口不一致       | 先核实地址可信，再重新输入并保存；不要反复向其他域名尝试密钥          |
| 400 参数错误               | 检查模型是否是文本对话型号、是否已退役、自定义根地址是否正确          |
| 401 密钥无效               | 去创建 Key 的同一平台官网检查或更换 Key                               |
| 403 没有权限               | 检查实名认证、模型权限或平台风控；不是反复点击就能解决                |
| 402 额度不足               | 去平台查看余额，或继续使用本地模式                                    |
| 404 找不到接口/模型        | Base URL 不加 `/chat/completions`；重新获取模型，或按网关文档手动填写 |
| 429 限频/配额限制          | 等待后手动重试，或检查平台配额；不要连续刷新                          |
| 超时、服务繁忙             | 本次先用本地结果；超时可能已经计费，不自动重复生成                    |
| 模型目录不支持/为空        | 仍可手动填写官方模型名，然后测试；目录失败不等于 Key 一定无效         |
| 没有正文/输出截断/格式错误 | 换适合短回答的对话模型，不把推理字段当回答                            |

服务响应可能含内部信息，DayMate 只展示固定的可操作说明，不显示完整错误正文。硅基流动状态码含义参考[官方排错文档](https://docs.siliconflow.cn/docs/userguide/faqs/error-code)。

## 开发者验证与隐私

常规 CI 只用本机模拟服务、虚构上下文和临时数据库；云端安装测试不用生产 Key。真实接口诊断是独立、显式、少量请求，不启动用户本机旧版，也不把 Key 上传 GitHub Secrets。

维护者可在 Windows 上使用 `scripts/probe-ai.ps1`，从当前用户已有 DayMate 系统凭据读取指定服务商的 Key，仅访问固定官方端点，不读取活动数据库。每次调用只发一个请求，不自动重试；独立诊断不计入正在使用的应用数据库，也不受其每日次数设置控制。默认获取目录；文本测试须显式给出型号，可能产生费用。输出仅含状态、已知字段结构、型号和文本长度，不打印密钥或正文。

```powershell
./scripts/probe-ai.ps1 -Provider siliconflow -Operation models
./scripts/probe-ai.ps1 -Provider siliconflow -Operation text -Model 'Qwen/Qwen3-8B'
./scripts/probe-ai.ps1 -Provider sensenova -Operation models
./scripts/probe-ai.ps1 -Provider sensenova -Operation text -Model 'sensenova-6.8-flash-lite'
```

不要把密钥写在命令行参数、脚本、截图或 Issue 中。密钥若曾出现在公开位置，请在供应商后台轮换；发布给其他用户的安装包从不预置维护者密钥。
