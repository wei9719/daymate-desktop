# 面向实际使用的 AI 工程复查

核对日期：2026-09-08。对应版本：v0.6.0。

## 选择依据

本次以当日可查阅的官方技术资料和项目实际故障为依据。保持 Tauri 2、React 19、TypeScript、Rust、SQLite 架构；AI 继续通过 OpenAI 兼容聊天协议连接用户选择的服务商。现有音乐推荐只需生成一个受限类别和一句理由，暂不引入复杂代理编排、向量数据库或远程工具执行。

| 工程实践         | DayMate 的落地方式                                                     | 用户获得的结果                           |
| ---------------- | ---------------------------------------------------------------------- | ---------------------------------------- |
| 后台执行耗时任务 | Tauri 异步命令将同步 HTTP 工作交给工作线程                             | 等待 AI 时仍可移动窗口、使用悬浮球       |
| 结构化输出与验证 | 硅基流动启用 JSON 模式；所有服务的结果再通过 Rust 类型、枚举和长度检查 | 错误结果不会变成未知操作或导致解析崩溃   |
| 数据最小化       | 默认只发送类别；汇总数据需选择分享并在调用前预览                       | 知道什么数据将离开本机                   |
| 可控消耗         | 原生层单请求并发、每日计数、15 分钟结果缓存、有限重试                  | 避免反复点击或切页产生大量调用           |
| 可降级的 AI 功能 | 请求失败、达到上限或输出无效时使用已有本地类别规则                     | 无网络、无余额时仍能获得音乐推荐         |
| 桌面权限边界     | HTTPS 地址解析、禁用重定向、WebView CSP、系统凭据保存密钥              | 减少意外发送密钥和执行远程脚本的机会     |
| 可复现发布       | 锁文件、版本校验、CI、CHANGELOG 提取和草稿发布                         | 每个下载包都有明确版本、变更记录和校验值 |

## 调用契约

设置保存在本机，密钥按服务商存入 Windows 凭据管理器。音乐推荐在确认后发送 `preferred_category`；只有选择分享时才增加 `active_minutes`、`unfinished_tasks`。系统提示词只定义类别选择与 JSON 格式，不包含个人数据。客户端显示的模型文本仅作普通文本，不执行命令，不打开 AI 生成的网址。

连接测试使用固定短句，必须收到非空聊天文本。成功状态码配合 HTML、空 JSON 或推理字段而没有正常文本均不能算配置成功。

每次实际发出的请求先在 SQLite 计数，包括连接测试、失败请求和重试。该数字是本机请求次数，不是服务商账单或 Token 统计。最多同时执行一个请求。连接失败及部分临时服务状态最多重试一次；超时不自动重发，以免重复产生费用。单次连接超时 5 秒、请求超时 25 秒。服务返回过长 Retry-After 时直接提示稍后再试。

缓存只驻留内存，15 分钟有效；类别、分享数据、服务地址、模型或服务商改变会使缓存不匹配，修改密钥会清空缓存。应用退出后缓存消失，日期与调用计数保留。

## 验证边界

使用本机测试服务器覆盖假成功响应、认证失败、临时故障重试、缓存命中、格式错误和重定向；使用临时数据库验证迁移与跨日预算；前端测试覆盖分享开关、确认流程和本地回退。真实第三方接口可单独做少量烟雾测试，CI 不需要生产密钥。

浏览器预览无法证明 Windows 自启或 Toast 已展示，必须结合桌面构建与安装后测试。系统免打扰可能抑制通知；提交通知不等于用户实际看见通知。
