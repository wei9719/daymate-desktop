# v0.9.0 验证记录

验证日期：2026-09-20。此记录将源码协议测试、真实模型推理、浏览器演示和原生安装测试分开，不把其中一种当作另一种。

## 真实本机模型：不启动旧版 DayMate

复用已有 Qwen2.5-1.5B-Instruct safetensors；没有下载、复制或修改模型，没有调用云端 Key，没有导入其他项目的 RAG、LoRA、聊天历史或文档。模型目录和运行目录不在公开报告中披露。

| 项目         | 本轮实际环境                         |
| ------------ | ------------------------------------ |
| Python       | 3.11.15                              |
| PyTorch      | 2.6.0+cu124                          |
| Transformers | 4.49.0                               |
| Accelerate   | 1.4.0                                |
| Safetensors  | 0.8.0                                |
| GPU          | NVIDIA RTX 2060，6 GiB               |
| 推理         | CUDA FP16，非流式、单路、确定性生成  |
| 模型校验     | safetensors SHA-256 与原下载清单一致 |

使用固定虚构的场景、心情和时间标签，不使用活动明细或真实任务。第一次连接返回有效短句；原长提示出现过非 JSON 音乐结果和非 JSON 鼓励语，因此没有把它当作通过。随后给本地生成增加 JSON 提示，为小模型使用包含明确格式示例的独立鼓励提示；云端提示不变，桌面解析不放宽。

最终代码的五项诊断全部通过，使用与桌面一致的原生提示和字段验证，不保留模型回答正文：

| 固定虚构场景                 | 耗时    | 输出 Token | 结果               |
| ---------------------------- | ------- | ---------- | ------------------ |
| 连接短句                     | 1.91 秒 | 3          | 有效正文，正常结束 |
| 专注 / 中性心情 / 陪伴此刻   | 4.28 秒 | 24         | 合法音乐类别与理由 |
| 休息 / 紧张 / 提一点精神     | 3.48 秒 | 19         | 合法音乐类别与理由 |
| 开始一天 / 低落 / 提一点精神 | 4.33 秒 | 24         | 合法音乐类别与理由 |
| 开始一天 / 疲惫 / 温柔鼓励   | 2.00 秒 | 11         | 合法鼓励 JSON      |

以上耗时不包含模型冷加载；冷加载可能需要数分钟。结构合格不等于个性化满意度，短场景样本也不证明任意输入稳定。`response_format` 在该服务中是提示约束，不是语法级强制解码；不合格输出仍由桌面拒绝并回退。

实际生命周期检查：第一次停止后 GPU 占用由约 3301 MiB 回落至 86 MiB；用最终代码重新启动并完成上述诊断后，由约 3375 MiB 再回落至 86 MiB。两次均确认本次父子进程退出、监听端口关闭，没有结束无关进程。重复启动返回同一个服务记录，没有再次加载模型。最终服务保持停止，由用户按需手动启动。

## 验证边界

- 没有安装、替换、启动或自动操控维护者本机旧版 DayMate。

- 未验证所有显卡/驱动、CPU 性能、Windows 10/11 完整交互和外设行为，也未宣称音乐满意度提升。

- Python 环境和模型不包含在安装包。使用方式见[本地 AI 指南](local-ai.md)。
- 上述既有推理环境用于兼容性实测，不是“全部依赖安全或最新”的承诺；本轮没有升级其他项目的环境，npm/Rust 发布审计也不覆盖这个外部 Python 环境。使用者仍需维护自己环境与模型来源的安全。
