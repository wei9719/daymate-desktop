# v0.8.0：研究依据与技术取舍

研究截止：**2026-09-12**。目标版本：**v0.8.0**。

这份文档回答“为什么这样优化”，实际代码入口和验证方法见 [工程手册](engineering-handbook.md)。它不是论文复现报告、音乐疗效研究或招聘市场统计，也不表示本版已经发布。实际测试结果应以对应提交的 CI、Release 记录与 [更新日志](../CHANGELOG.md) 为准。

## 结论先看

DayMate 要补的是可验证的推荐过程，而不是更多框架：

1. 从真实曲目目录召回候选，先验证可播放资格，再结合用户明确选择的场景、偏好和反馈进行本地排序。
2. 展示排序所依据的真实信息，不让大模型编造歌名、播放地址、歌曲属性或用户心理状态。
3. 建立固定用例和回归标准，分别检查功能正确性、推荐质量与用户体验，不能用其中一项代替另外两项。
4. 继续采用 React / Tauri / Rust / SQLite / BYOK；没有证据表明当前规模需要向量数据库、多 Agent 运行时或 GPU 音频模型。

上述是结合资料与项目现状形成的工程判断；本版参数和规则不是任何论文的复现结果。

### 许可与音乐授权边界

- TalkPlay-Tools 官方仓库标注 **CC-BY-NC 4.0**，示例还明确因许可限制返回 Spotify 链接，而非直接音频。这不是可以直接复制进 DayMate MIT 分发包的通用播放器或免费曲库。本项目只参考公开设计思路，不引入其代码、索引、音频或歌词数据。
- 论文开放阅读、代码开放下载、曲目允许流播、音频允许重新分发是不同问题，不能互相替代。
- Audius 曲目通过平台允许的播放入口读取；过滤付费/门控、已删除、未公开或不可用候选，不绕过会员、登录或版权限制。平台公开流播不等于可以将整个曲库打包分发。
- 随包离线音乐使用项目已列明来源的 CC0 资源；用户导入的本地音频留在其本机。来源说明见 [隐私说明](../PRIVACY.md) 和 [用户手册](../USER_GUIDE.md)，具体曲目元数据在 `src/services/music.ts`。
- 本次不增加生成音乐服务或商汤图片模型：图片生成能力、模型权限、费用、内容权利与聊天接口兼容性应另行核验，不能从“同一家服务商”推断已获授权。

## v0.8.0 决策记录

### D1：使用候选内的本地混合排序

“混合”指明确偏好、场景元数据、用户反馈与近期重复控制共同参与排序，不表示已经实现协同过滤、向量检索或训练出的推荐模型。

AI 可提出受控类别建议；本地代码决定候选资格、排序与播放入口。没有可靠元数据时不猜测 BPM、歌曲语言、情绪标签或相似度。排序解释来自实际命中的规则，而非自由生成的个性化故事。

### D2：反馈保持本地、规模有界

本版音乐反馈以至多 200 条的有界记录保存在 WebView 本地存储，不上传 AI；当前场景、心情和近期播放 ID 只在内存中。任务和偏好也仍在 WebView 本地存储。SQLite 目前保存活动会话、迁移版本和每日 AI 调用次数，**不是所有数据的统一数据库**。

两窗口同源，因此原生命令权限分离不等于 WebView 存储隔离。API Key 单独在 Windows 凭据管理器，不进入任务或反馈存储。将任务、偏好和反馈迁移到 SQLite 是未来方案，需要独立迁移与回归测试。

### D3：当前心情与期望变化由用户决定

“贴合现在”和“轻轻提振”表达的是用户选择的音乐意图，不是系统诊断。应用不从鼠标、键盘或窗口标题推断心情，不承诺音乐能治愈、缓解或识别疾病。

### D4：把评测作为版本化工程产物

使用既有测试栈保存固定候选与场景，检查受限曲目过滤、反馈生效、解释依据、去重、回退和同输入可复现。`src/data/music-eval-v1.json` 包含 12 个手工编写合成场景和 12 首虚构曲目，`npm run eval:music` 对比新策略与旧日期轮换基线，输出标签命中与覆盖度；这些是合成策略指标，不是满意度或疗效证据。真实 BYOK 测试须显式授权且与默认离线回归分开，避免每次 CI 消耗用户额度。

人工偏好、实际收听满意度与长期情绪影响尚未建立有效样本；不报告虚构准确率、点击率提升或情绪改善幅度。有标注相关性数据后才适合讨论 NDCG/Recall 等排序指标。

### D5：不把热门技术当成交付目标

暂不引入 RAG、向量数据库、多 Agent、模型微调、GPU 音频嵌入或云端画像。只有候选规模、真实需求及基线评测说明现有方案不足时，再提出带成本、隐私和许可评估的替代方案。

## 验收标准，不是预先宣布的成绩

- 受限、隐藏或不喜欢且被规则排除的歌曲不能绕过过滤进入推荐。
- 推荐理由只能引用本地可证实的规则和字段；不能产生目录外歌名或播放地址。
- 换页、收起主窗口与正常切换视图不应销毁音乐控制器；播放失败有可恢复提示。
- 反馈可清除、数量有界，音乐反馈和近期播放 ID 不会进入 AI 请求；场景/心情等显式字段仍按发送预览处理。
- 日期回顾按所选本地日期查询；昨日没有记录时显示空状态，而不是今日数据。
- 专注会话恢复、退出前活动落库和旧存储恢复分别有回归用例。
- 发布必须经过现有代码质量、安全、浏览器 UI 与四组 Windows 安装冒烟门禁；云端 Windows Server 检查不能替代 Windows 10/11 真机完整验收。
