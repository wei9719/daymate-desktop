# 0.7.0 AI 与音乐验证记录

验证日期：2026-09-08。此记录区分真实供应商请求、模拟服务回归、浏览器界面验证与 Windows 安装检查，不把其中一种结果当作全部功能验证。

## 真实云端接口

诊断在独立进程中读取当前 Windows 用户已经保存的指定平台凭据，访问该平台官方云端地址；没有启动、升级或操作本机正在使用的旧版 DayMate，没有读取真实活动数据库。没有将生产密钥上传到 GitHub、CI 或安装包，也没有写入脚本和报告。

| 接口与操作                    | 已观察结果                                               | 结论与限制                                                         |
| ----------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------ |
| 硅基流动聊天模型目录          | HTTP 200，返回 65 个模型标识                             | 获取目录正常；不据此宣称所有模型均免费或都有权限                   |
| 硅基流动 Qwen/Qwen3-8B 短文本 | HTTP 200，有有效中文正文                                 | 当前账号和该型号可调用                                             |
| 新 Rust 运行时的硅基流动集成  | 目录、连接测试、音乐 JSON、鼓励 JSON 四阶段通过          | 使用虚构场景、无活动摘要；独立临时数据库，最多 6 次请求预算        |
| 商汤模型目录                  | HTTP 200，返回 8 个模型标识，含 6.8 文本与 U1.5 图片型号 | 目录可读取，不能当作推理/生图已验证                                |
| 商汤 6.8 短文本               | 初次诊断失败、一次 200 无正文，后续为 429                | 不能宣称文本生成实测成功；收到限频后停止连续重试                   |
| 商汤 6.8 调整后的预算         | 2000 输出 Token、60 秒超时的单次请求仍为 429             | 适配有官方依据与模拟回归，实际正文仍需服务商额度/限频恢复后再验证  |
| 商汤图片生成                  | 未调用                                                   | 仅核对官方接口与鉴权，不验证权限、不产生图片费用；0.7.0 未上线生图 |
| Audius 专注音乐搜索           | 无密钥查询，HTTP 200，40 首候选                          | 证明目录可访问，不代替逐首音频播放验证                             |
| Audius 国风关键词搜索         | 无密钥查询，HTTP 200，0 首候选                           | 不保证国风或指定商业歌曲可用；提供明确提示和离线回退               |

商汤官方说明 `max_tokens` 同时包含推理和正文，因此极短预算存在耗尽后没有正文的可能。此次兼容调整仅针对官方根地址及精确 6.8 型号，不向任意网关或其他模型扩大预算，不显示推理字段，也不在限频/超时后无限重试。[官方依据](https://github.com/OpenSenseNova/SenseNova6.8/blob/main/API.md)

## 自动回归范围

本地最终回归为前端 177 项、Rust 49 项、发布/审计脚本 21 项，共 247 项通过；另有 1 项显式硅基流动真实集成测试通过。首次全量前端运行遇到 worker 启动超时，待并行编译结束后完整重跑 13 个文件、177 项通过，没有忽略该错误或跳过失败文件。格式、类型、Lint、Clippy 和构建另行检查；最终云端结果仍以本版 Actions 为准。

- 本地单元测试覆盖平台档案切换和恢复、拒绝把密钥放到普通设置、模型目录解析、有限缓存、每日预算、配置变更后丢弃旧结果及 URL 绑定。
- 场景/心情/语气是明确输入；音乐建议与鼓励分别校验并缓存，错误返回使用本地回退。
- 手动搜索或选择音乐类别会作废较早的 AI 音乐请求；不会因此更改每日好句或鼓励。
- 音乐候选缓存覆盖 16 池上限、10 分钟有效期、并发合并、失败不缓存、不同场景不串文案，以及受限曲目排除。
- 常规 CI 不需要真实 API Key；真实硅基流动集成测试保持默认跳过，只有明确执行 `scripts/windows-desktop.ps1 live-ai-test` 才运行。

## 云端界面与安装

浏览器测试使用 GitHub 托管环境、虚构本地偏好和明确标注的音乐接口样例；截图只用于检查设置与内容页布局。这不是真实 Windows Credential Manager、Tauri IPC、音乐 CDN 或 AI 服务的界面端到端验证。

正式安装包仍必须通过 Windows Server 2022/2025 × 全新数据/合成旧数据的四组安装检查，然后才公开 Release。它们验证安装、初始化、旧库记录保留和单实例，不代替 Windows 10/11 实机上的完整界面、外设、托盘、通知、自启或长时间播放。
